# Queue Master — специфікація бота

Telegram-бот для черги на здачу лаб у груповому чаті. Google Sheets і зовнішні API не потрібні: список живе в боті, а «таблиця» — це закріплене повідомлення в групі, яке бот редагує.

## 1. Основна ідея

- Староста створює чергу з часовими слотами, як у звичній таблиці: час | ім'я | ✅.
- Студенти записуються самі, кнопкою або командою.
- Бот тегає того, чия черга, і попереджає наступного.
- Студент натискає «✅ Готово» — бот ставить ✅ і кличе наступного.

Бонус: студенти записуються зі свого акаунта, тож бот одразу знає їхній `user_id` і може тегати будь-кого, навіть без @username. Окремо прив'язувати імена не потрібно.

## 2. Вигляд закріпленого повідомлення

```
📋 Лаба 3 — ООП
🟢 Приймають · здали 2 з 9

10:25 ✅ Коваленко Олена
10:35 ✅ Бондар Марта
10:40 ▶️ Шевчук Тарас            ← здає
10:30 ⏳ Ткаченко Андрій ↩️      ← готується
10:45 ▫️ Мельник Ірина
10:50  ·  —
10:55 ▫️ Кравець Софія
── перерва ──
11:10 📣 …                       (📣 — покликали, ще не натиснули «Йду»)
11:15 ⏭ Лисенко Богдан          (пропущено)

[✋ Записатися] [📍 Де я?]
[🏃 Йду]        [✅ Готово]
[⏬ Пізніше]    [🚪 Заходжу]
[❌ Виписатися]
```

Бот редагує одне це повідомлення, а не шле нові. Нове повідомлення з'являється тільки разом із тегом «твоя черга», і попереднє таке бот видаляє, тож у чаті завжди лише одне актуальне.

↩️ означає, що людина повернулася після пропуску. Її рядок стоїть уже не за часом, а там, де вона тепер у черзі.

## 3. Команди і кнопки

### Для всіх

| Кнопка / команда | Що робить |
|---|---|
| **✋ Записатися** | займає перший вільний слот; якщо тебе пропустили — повертає в чергу (як «Я тут») |
| `/join 10:45` | займає конкретний слот (якщо він вільний) |
| **📍 Де я?** | спливаюче вікно лише тобі: скільки людей попереду й орієнтовний час |
| **🏃 Йду** | тебе покликали, ти йдеш (інакше автопропуск) |
| **✅ Готово** / `/done` / відповідь «Закінчив» на повідомлення бота | здано, бот кличе наступного |
| **🚪 Заходжу** / `/enter` | для наступного в черзі: попередній вийшов або не прийшов, а ти заходиш (див. розділ 4) |
| **⏬ Пізніше** / `/later` | помінятися місцями з наступним у черзі |
| **🙋 Я тут** / `/here` | пропущений повертається в чергу (зі штрафом, див. розділ 4) |
| **❌ Виписатися** / `/leave` | звільнити свій слот; кнопка спрацьовує з другого натискання протягом 5 с |
| `/name Прізвище Ім'я` | як показувати тебе в черзі (за замовчуванням — ім'я з Telegram) |
| `/help` | усі команди |

- Кнопки відповідають спливаючим вікном, яке бачить лише той, хто натиснув.
- Успішні команди бот підтверджує реакцією 👍.
- На помилку в команді бот відповідає в чаті, і ця відповідь зникає через 15 с (довгі підказки — через 90 с).

«✅ Готово» приймається тільки від того, хто **зараз здає**, або від адміна. Як «Закінчив» у відповідь на повідомлення бота рахуються (без урахування регістру): `закінчив`, `закінчила`, `готово`, `все`, `здав`, `здала`, `здано`, `done`.

### Для адмінів групи

| Команда | Що робить |
|---|---|
| `/new Лаба 3 10:25-13:00 5 перерва 12:00-12:20 чекати 3` | створює чергу: назва, проміжок, крок у хвилинах, перерви, скільки чекати на «Йду». Усе після проміжку необов'язкове. Кінець проміжків **не включно**: `10:25-13:00` → останній слот 12:55 |
| `/go` | запускає чергу і тегає першого |
| `/skip` | поточний не прийшов: пропуск зі штрафом, бот кличе наступного |
| `/wait 5` | скільки хвилин чекати на «🏃 Йду» (0 — без автопропуску) |
| `/done 10:45` | відмічає конкретний слот як здачу (викладач прийняв когось поза чергою) |
| `/repost` | надсилає повідомлення черги заново вниз чату і закріплює |
| `/add 10:45 Прізвище Ім'я` | вписує людину без Telegram (без тегу) |
| `/remove 10:45` | звільняє слот |
| `/close` | закриває чергу, відкріплює повідомлення |

Адмін — це адміністратор Telegram-групи (перевіряється через `getChatAdministrators`).

## 4. Логіка черги

Кожен слот має статус: `empty` → `waiting` → `current` → `done` або `skipped`.

- **Порядок виклику** — це порядок слотів у списку. Спочатку він збігається з часом, але той, хто повернувся після пропуску, переїжджає далі разом зі своїм часом-міткою.
- **Наступний** = перший слот у списку зі статусом `waiting`. Він же отримує «готуйся».
- Порожні слоти просто пропускаються.
- Після `/go` записатися можна тільки в слот **після** поточного: у минулі слоти не можна, щоб не перестрибувати чергу. Якщо всі вже здали, новий записаний одразу стає поточним.
- Коли кликати більше нікого — бот пише «🎉 Більше нікого в черзі».

### Неявки й автопропуск

1. Бот кличе людину (📣 «кличемо…»). Вона має натиснути **🏃 Йду** протягом `wait_minutes` (за замовчуванням 3 хв), і тоді статус стає ▶️ «здає».
2. **Покликали раніше за розклад** (черга йде швидше): відлік починається з **часу її слота**, а не з моменту виклику. Прийти на свій час — не порушення. В оголошенні бот пише конкретний час: «Натисни «🏃 Йду» до 11:43».
3. Не натиснула вчасно → **автопропуск**. Статус стає `skipped`, і бот одним повідомленням пише «⏭ X не відгукується — пропускаю» та кличе наступного.
4. Пропущений натискає **🙋 Я тут** (або ✋, або `/here`) і повертається зі штрафом:
   - після 1-го пропуску вперед іде **1** людина з тих, хто чекає;
   - після 2-го — **2** людини;
   - з 3-го — він іде **в кінець** (після останнього записаного).
5. Людей без Telegram (`/add`) автопропуск не чіпає, бо вони не можуть натиснути кнопку.
6. Після перезапуску бота таймери відновлюються, але з мінімум хвилиною запасу.

### «🚪 Заходжу» — коли попередній забув або не прийшов

Натиснути може тільки наступний у черзі (через 60 с після виклику поточного) або адмін. Що сталося з попереднім, бот вирішує сам:

| Попередній… | Що буде з ним |
|---|---|
| натискав «Йду» (або він без Telegram) | він був у кабінеті й вийшов, але забув «Готово» → ✅ ставиться автоматично |
| не натискав, і його час уже настав | не прийшов → ⏭ пропуск зі штрафом |
| не натискав, але його покликали раніше за розклад | без штрафу: він просто йде одразу після того, хто зайшов |

Хто натиснув «Заходжу», одразу стає поточним і вже «здає», а наступному за ним бот пише «готуйся». Так ланцюжок не переривається.

Якщо «Готово» поставили автоматично помилково (людина ще не здавала), вона натискає **🙋 Я тут** і повертається **без штрафу**, одразу після поточного.

### Нагадування

- Коли людина натискає «🏃 Йду», бот у спливаючому вікні нагадує натиснути «✅ Готово», як вийде.
- Якщо здача триває **удвічі довше за середню** (рахується за останніми 5 людьми, але не менше 10 хв), бот один раз пише: «⏰ @X, ти ще в кабінеті? Якщо вже все — натисни «✅ Готово»». У цьому ж повідомленні він підказує наступному, що можна натиснути «🚪 Заходжу».

## 5. Технічні рішення

- **Privacy mode залишається увімкненим.** Бот бачить тільки команди й відповіді на свої повідомлення. Цього достатньо, читати весь чат не треба.
- **Топіки (forum):** черга прив'язана до `chat_id + message_thread_id`, бот пише в той топік, де її створили.
- **Одна активна черга на чат/топік.** Два викладачі одночасно — це дві черги в різних топіках.
- **Ліміти Telegram** (~20 повідомлень/хв у групі): закріплене повідомлення редагується не частіше разу на секунду, помилка `message is not modified` ігнорується.
- **Свої повідомлення бот видаляє без прав адміна.** Так він прибирає старі «твоя черга» і відповіді-помилки.
- **Часовий пояс слотів** задається в `.env` (`TIMEZONE`, за замовчуванням `Europe/Kyiv`). Він потрібен, щоб порівнювати «10:25» зі справжнім часом.

## 6. Стек

- Python 3.12+
- aiogram 3 (long polling)
- SQLite через aiosqlite
- tzdata (база часових поясів, потрібна на Windows)

## 7. Модель даних

```
queues
  id, chat_id, thread_id, title, step, wait_minutes,
  message_id (закріплене), status (open | running | closed),
  created_by, created_at

slots
  queue_id, position (порядок виклику), time ("10:25"),
  user_id (nullable), name (nullable),
  status (empty | waiting | current | done | skipped),
  skips, called_at, confirmed, done_at, nudged, auto_done

users
  user_id, name (з команди /name)
```

## 9. Відкриті питання

- Чи потрібна «пам'ять» між парами (хто не встиг — першим наступного разу)? Поки що ні.
- **Кілька черг в одному чаті без топіків** (наприклад, запис на дві різні пари одночасно). Поки що потрібні топіки.
- **Вибір часу кнопками** в особистому чаті з ботом (зараз конкретний час — тільки через `/join 10:45`).
