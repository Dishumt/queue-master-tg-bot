# Queue Master

Telegram-бот для черги на здачу лаб у груповому чаті. Студенти стають у чергу, бот тегає того, чия черга, і кличе наступного, коли попередній написав «Закінчив».

- Що бот уміє: [docs/SPEC.md](docs/SPEC.md)
- Як влаштований код: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

## Як запустити

1. **Створи бота** в [@BotFather](https://t.me/BotFather): `/newbot` → отримаєш токен.
   Privacy mode **не вимикай**: бот і так бачить команди та відповіді на свої повідомлення.
2. **Налаштуй проєкт:**
   ```powershell
   uv sync
   copy .env.example .env
   ```
   Відкрий `.env` і впиши `BOT_TOKEN=...`.
3. **Запусти:**
   ```powershell
   uv run python -m bot
   ```
4. **Додай бота в групу** і зроби його адміном із правом **закріплювати повідомлення**
   (видаляти чи банити не потрібно).
5. В групі адмін пише:
   ```
   /new Лаба 3 перерва кожні 5
   ```
   Студенти тиснуть «✋ Записатися», адмін пише `/go`, і далі все йде само.
